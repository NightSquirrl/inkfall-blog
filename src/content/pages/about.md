## 关于本站

这里是一处用来沉淀学习笔记与技术记录的地方，内容来自日常的学习与实践，目前围绕以下几个方向展开：

- **后端开发** —— 以 Java 为主线，覆盖基础语法、面向对象、集合、IO 流、多线程与反射；并延伸到 JavaWeb 生态，包括 Maven、Spring Boot、MyBatis、Redis、JWT 与 AOP 等。
- **前端开发** —— 记录 JavaScript、TypeScript、Vue 与 React 的实战心得，以及 HarmonyOS、Three.js、uni-app 等方向；同时整理 Webpack 工程化与前端性能优化经验。
- **运维与工具** —— 整理 Docker、NGINX、MySQL、Git 与 Node 版本管理等日常工具的使用，以及服务器初始化、图床等环境配置。
- **面试准备** —— 汇总 JavaScript、Vue、React 与 TypeScript 的面试题，便于回顾与查漏补缺。

截至目前，站内已积累 100 余篇笔记，分属于上述四个分类。所有文章均以 Markdown 书写，便于检索与长期维护。
